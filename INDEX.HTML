INFORMACION DE CSS.

¿QUE ES Y PARA QUE SIRVE? Es el lenguaje que se utiliza para definir la apariencia visual y el diseño de los documentos escritos en HTML. .

Cuál es la diferencia entre HTML y CSS?

HTML define la estructura y el contenido de una página web, mientras que CSS se encarga del diseño y la apariencia visual.

¿DONDE ESTA UBICADO?

El archivo CSS externo no tiene una ubicación única y fija, sino que se guarda dentro de la carpeta del proyecto web creada por el desarrollador, por lo general en la raíz o en una subcarpeta llamada css o styles
